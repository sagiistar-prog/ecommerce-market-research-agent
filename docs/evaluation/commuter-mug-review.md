# 保温杯练习判断

**暂不把轻便定为新品主卖点；把它列为首个待验证的候选优势。** 目标是让通勤者把热饮方便地带到目的地，现有材料还不能证明重量是主要问题，也不能证明轻量杯保温表现如何。

- E001 已使用 “Light enough for commuting”，空重 220 g；E002 空重 310 g，主张 “Warm drink on arrival”；E003 为 250 g。全部是 E0 虚构记录，能帮助设定比较方案，不能证明真实需求或独特性。
- A 与 B 空重相差 90 g，但若用 350 ml 饮品约重 350 g 的练习假设，满载总重约为 570 g 与 660 g，差幅约 13.6%。空杯减重约 29.0% 并不等于用户感受到同样幅度的改善；放在包里时尤其需要实际验证。
- 两个虚构价格的中位数为 USD 26.70；C 的价格未知。这不能支持新品定价，当前决策也无需为了补齐价格而推迟重量验证方案。

最小下一步是先核实携带场景，再做配对体验：先请 3 位目标用户回顾最近一次通勤，确定手提还是放包、持续多久和最困扰的环节；随后以 12 人探索样本为提案，让每人随机顺序体验外形相同、容量同为 350 ml、空重分别模拟 220 g 与 310 g 的载具。用等量常温液体隔离携带重量，记录 1–7 分负担评分与最终选择。保温及密封另做工程测试，常温携带实验不能证明热饮性能。

**建议在实施前共同确定的探索门槛**：负担评分中位改善至少 1 分、至少 8/12 人选择轻载具，同时不增加掉落、操作失败或洒漏，才进入下一阶段。未达门槛就先放弃“轻便主卖点”；保温或密封达不到预先约定的需求，则先改设计。门槛是提案，不是测量结果；通过也只支持继续验证。

携带收益和工程要求通过后，再私下比较同一产品的“轻便通勤”与“到达时仍温热”两个概念版本，保持图片、价格和事实信息一致，随机分组，衡量愿意进一步了解的比例及误解比例。先约定最小有用差异、样本量和停止规则，才能据结果决定候选主卖点。公开广告、保温或安全声明另需专业审查。
